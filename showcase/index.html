Every question goes to the cheapest model that can settle it

The Agentic Ontologist orchestrates four memory-augmented agents to integrate two ontologies: KROMA matches classes, extraction finds missing relations, reasoning places classes that have no match, and validation removes matches that contradict each other. This is one recorded run on the OAEI Mouse–Human anatomy track, with every decision and what it cost.
