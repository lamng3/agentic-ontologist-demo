Route each question to the cheapest model that can settle it

The Agentic Ontologist is an orchestrator and four memory-augmented subagents (KROMA for matching, extraction, reasoning, and validation) that integrate ontologies, each question routed to the cheapest model that can settle it. Around them, a toolkit loads an ontology, retrieves nearby concepts, and answers with a language model.
